# مكبس PDF

أداة تضغط ملفات PDF الممسوحة بالسكانر (كشوفات، فواتير، سندات) وتشتغل كاملة داخل المتصفح. تختار الحجم اللي تبيه بالعداد، تشوف معاينة للصفحة قبل وبعد الضغط، وإذا ما كانت واضحة تزوّد الحجم.

**جرّبها:** https://ahmedalikhudare-lang.github.io/mikbas-pdf/

## المميزات

- **الملفات ما تنرفع لأي مكان.** كل الضغط يصير في جهازك، فهي آمنة للكشوفات البنكية والمستندات الخاصة.
- **عداد للحجم:** تكتب كم ميجا تبي، أو تحرك المؤشر، والأداة تختار أعلى وضوح يناسب هذا الحجم.
- **معاينة قبل وبعد:** على أي صفحة، بتكبير 100% و200%. اضغط مطولاً على الصفحة تشوف الأصل.
- **ثلاثة أوضاع:**
  - **ملوّن:** للفواتير والسندات اللي فيها أختام وكتابة بالقلم.
  - **رمادي:** أصغر شوي من الملوّن ويحافظ على الكتابة الباهتة.
  - **أبيض وأسود:** أصغر حجم وأوضح خط للكشوفات والمستندات المطبوعة.
- **أكثر من ملف مرة وحدة**، مع خيار تدمجها في ملف واحد.

## طريقة الاستخدام

1. أضف ملفات PDF بالسحب أو بالضغط على «أضف ملفات PDF».
2. اختر نوع الضغط.
3. حدّد الحجم المطلوب بالعداد وشوف المعاينة.
4. اضغط «اضغط الملفات» وبعدين «حفظ».

## كيف تشتغل

- تقرأ الصفحات وترسمها بمكتبة [pdf.js](https://github.com/mozilla/pdf.js) بنفس دقة المسح الأصلية.
- الوضع الملوّن والرمادي يحفظ كل صفحة كصورة JPEG، ويختار الدقة والجودة حسب الحجم المطلوب.
- وضع الأبيض والأسود يحفظ الصفحة بترميز CCITT Group 4، وهو مكتوب داخل الأداة نفسها ومتوافق مع كل برامج قراءة PDF.
- أثناء الضغط تتابع الأداة الحجم صفحة بصفحة، وتضبط الإعداد عشان الملف النهائي يطلع قريب من الرقم اللي اخترته وما يتعداه.

الأداة صفحة HTML واحدة بدون سيرفر وبدون أي خطوات بناء.

**Mikbas PDF** is a single-page, client-side tool for compressing scanned PDFs to a target size, with a before/after preview. Files never leave the browser. It renders pages with pdf.js and re-encodes them as JPEG (color/grayscale) or CCITT Group 4 (black & white), steering quality page by page so the output lands just under the size you choose.
